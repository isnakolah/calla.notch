# Routing examples

“Why did you design your take-home this way?” → Call answers with relevant Part 1
facts and personal context. Suspend the current edit; do not ask a coding worker
to independently answer the same utterance.

“Tell me about a difficult project.” → Normal Call question and history. Retrieve
compact relevant personal context; do not force a coding answer.

“How should sum treat empty cells?” → Call answer may identify the ambiguity and
suggest a concrete clarification. Do not record a policy as accepted yet.

“Actually, ignore text inside ranges, but reject an explicit text argument.” →
Confirmed correction: update requirements; invalidate affected proposals and
checks. Return to the suspended sum task after discussing the change.

“What if we ignored all strings?” → Explore a hypothetical. Do not change policy.

“Maybe look at Range.indices.” → Hint: inspect the API; not a completed task.

“I am adding the loop now.” → Narration; keep the current move visible.

“I saved it.” → Saved observation; no completion claim.

“Back to the range expansion.” → Restore that unfinished task and reading place.

“Continue.” → Explicit task advance, separate from a verification claim.

“Run the check.” → Run the staged command in the private shadow directory and
show actual output, exit status and revision on demand.

“That error is from my unsaved buffer.” → Editor evidence; do not attach a saved
revision or claim the shadow check reproduced it. Ask for a save if needed.
