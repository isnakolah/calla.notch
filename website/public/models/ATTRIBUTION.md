# Anatomical brain model

Kristen Browne; Heidi Schlehlein. 2023. *3D Reference Organ for Brain, Male v1.3*.
HuBMAP Human Reference Atlas. https://doi.org/10.48539/HBM929.XKCL.339

Source: https://github.com/hubmapconsortium/hra-kg/tree/main/digital-objects/ref-organ/brain-male/v1.3/raw

Derived from the Allen Human Reference Atlas – 3D, 2020 (Ding et al., 2016).
Changes for this website: merged structures, omitted optic chiasm, simplified mesh,
centred and uniformly scaled, packed half-float positions and normals; new cyan materials.
The visual neurons represent work relationships, not biological activity or a medical simulation.

Current neural rendering: continuous cortex reconstruction with volumetric
smoothing, simplification to 60,000 faces, curvature contour extraction, and
surface-following routes between illustrative knowledge nodes. The anatomical
surface provides a faint depth layer beneath the neural threads.
`brain-neural-fallback.jpg` captures that same rendering as a static alternative.
