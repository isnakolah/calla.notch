# Source provenance

calla.notch is a customized fork of
[Boring Notch by TheBoredTeam](https://github.com/TheBoredTeam/boring.notch).
Original source authorship and copyright notices remain in the source files.
The application remains licensed under the repository's [GPL license](../../LICENSE).

The original application icon is credited to
[@maxtron95](https://github.com/maxtron95); the upstream website was credited to
[@himanshhhhuv](https://github.com/himanshhhhuv).

Other original acknowledgments include
[MediaRemoteAdapter](https://github.com/ungive/mediaremote-adapter) and
[NotchDrop](https://github.com/Lakr233/NotchDrop). Dependency notices remain in
`THIRD_PARTY_LICENSES`, `Tutor/NOTICE.md`, and `Distribution/Licenses/`.

The documents in this folder are immutable pre-rebrand records. Their old
product names, branch names, paths, release identifiers, and validation results
describe historical work. They are not installation instructions or runtime
proof for calla.notch. Git history also retains original source material.

Current instructions are in [the installation guide](../private-installation.md)
and [migration and recovery](../branding-migration.md).
